# JDS Energy Orçamentos

App de orçamentos, agenda, clientes e recibos para serviços elétricos. Roda no navegador, pode ser instalado na tela inicial e funciona sem internet.

Os dados digitados ficam só no aparelho (IndexedDB) e não são enviados a este repositório. Use **Ajustes > Baixar backup** para guardar ou passar os dados para outro aparelho. **Nunca coloque o arquivo de backup aqui.**
